# Q1 ROS 2 仿真代码 · 0.1.0-preview.2

本代码增量将自研 Q1 Dynamics R2 接入原生 ROS 2，适用于已有私有 Q1 工程的开发者。

- 两个独立 ROS 工作区，使用通信域 221/222 和各自的输出目录。
- ROS 2 服务可运行站立、下蹲起身及基础步态，支持暂停、停止和明确重置。
- 发布物理计算得到的关节状态、机身里程计、TF、运行状态和仿真时钟；每次场景独立保存结果及逐步轨迹。
- **先设置参数，再启动仿真**：将 `config/q1/simulation_parameters.example.json` 复制到私有模型目录并命名为 `simulation_parameters.json`，或在 ROS 入口指定 `--config`。每次新场景读取配置，正在运行的场景保持启动时参数；无文件时使用已验证的稳定慢行默认值。
- 每次运行的 `parameters.json`、`result.json` 记录实际加载的参数及摘要、模型文件摘要与编译后的物理参数摘要，便于核对配置是否生效。字段、允许范围与操作步骤见归档内 `docs/Q1_SIMULATION_PARAMETERS.zh-CN.md`。

**验证环境：Ubuntu 24.04、Python 3.12、ROS 2 Jazzy、MuJoCo 3.3.7。** 三次原生 DDS/Q1 物理仿真通过 34 项检查，覆盖双工作区、站立、起身、行走、状态反馈和工作区隔离；四组离线参数应用及物理场景检查、十项源码测试通过。另验证了 Cloud 编程仿真调用与 V1.3 外观视频渲染；该编程运行器不属于本源码压缩包。验收报告的适配器哈希与发行源码一致。

下载 `omindos-q1-ros2-0.1.0-preview.2-source.zip`，解压后先阅读 `README.md` 和参数指南。归档内的 `SOURCE_MANIFEST.json` 记录原仓库精确提交与文件哈希；`SHA256SUMS.txt` 可核对下载，`NATIVE_VALIDATION.json` 提供完整验证摘要。

此包包含 ROS 2 接入源码、参数示例和安装指南；**必须使用所有者本地已有的 Q1 Dynamics R2 私有模型及控制器**。原始 STEP、机械参数、网格及私有控制源码不在公开发行内。MuJoCo 等依赖按指南中的固定版本安装。

本版完成软件物理仿真接入，尚无电机使能、CAN/串口控制或实机验收。质量、惯量、接触与执行器沿用 R2 待标定情景。这是独立的 Q1 开发代码增量，不替换原 Ubuntu 完整安装包。
